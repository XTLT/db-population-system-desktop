# 证书固定部署说明

此目录用于存放服务端的 SSL 证书文件，实现证书固定（Certificate Pinning）。

## 部署步骤

### 1. 获取服务端证书

服务端证书位置：`server/certs/server.crt`

如果服务端尚未生成证书，运行服务端时会自动生成。

### 2. 复制证书到此目录

```bash
# 从服务端复制证书到 Desktop 客户端
cp ../server/certs/server.crt ./server.crt
```

### 3. 重启客户端

证书文件存在时，客户端会自动启用证书固定验证。

## 安全说明

- **有证书文件**：启用证书固定，仅信任此证书
- **无证书文件**：跳过证书验证（不安全，仅限开发环境）

## 生产环境

生产环境部署时，请确保：
1. 服务端证书已生成
2. 证书文件已复制到此目录
3. 不要将私钥文件（server.key）分发到客户端
