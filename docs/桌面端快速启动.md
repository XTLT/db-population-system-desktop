# 桌面端快速启动指南

## 启动方式

### 1. 本地模式

如果数据库在本地，直接选择"本地模式"即可。

### 2. 网络模式

连接远程服务器：

1. 启动服务端（在服务器上）：
   ```bash
   ./start_server.sh start
   ```

2. 启动桌面端，会自动显示连接对话框

3. 系统会自动扫描局域网服务器（约5-10秒）

4. 如果找到服务器，点击"连接"即可

5. 如果未找到，可以手动输入服务器地址：
   - 内网地址：`https://192.168.x.x:5000`
   - 本机地址：`https://127.0.0.1:5000`
   - IPv6地址：`https://[xxxx:xxxx::xxxx]:5000`

## 服务器地址保存

桌面端会自动保存最近使用的5个服务器地址，下次启动时可以直接选择。

保存位置：
- Linux: `~/.config/人口通/recent_servers.json`
- Windows: `%APPDATA%/人口通/recent_servers.json`

## 常见问题

### Q: 扫描不到服务器？

检查：
1. 服务器是否启动（访问 `https://服务器IP:5000/api/health`）
2. 防火墙是否开放 5000 端口
3. 是否在同一局域网内

解决方法：
- 手动输入服务器地址
- 检查网络连接

### Q: 连接超时？

可能原因：
1. 服务器未启动
2. 网络不通
3. SSL 证书问题

解决方法：
- 先在浏览器访问服务器地址确认可用
- 确认服务器正在运行

### Q: 如何清除保存的服务器地址？

删除配置文件：
```bash
# Linux
rm ~/.config/人口通/recent_servers.json

# Windows (PowerShell)
Remove-Item "$env:APPDATA\人口通\recent_servers.json"
```

## 内网和 IPv6 访问

### 内网访问

服务器监听所有网络接口，内网访问格式：
```
https://192.168.x.x:5000
```

### IPv6 访问

如果服务器有 IPv6 地址，访问格式：
```
https://[2001:db8::1]:5000
```

注意：IPv6 地址需要用方括号 `[]` 包围。

## SSL 证书

### 自签名证书（默认）

服务器默认使用自签名证书。

**证书固定部署（推荐）**:

```bash
# 1. 启动服务端生成证书
cd server && python app_modular.py

# 2. 导出证书到桌面端
cd server && python cert_manager.py export --desktop

# 3. 证书会自动保存到 desktop/certs/server.crt
```

**验证方式**:
- 有证书文件：启用证书固定验证 ✓
- 无证书文件：跳过验证（仅开发环境）⚠️

### 正式证书

如果使用正式证书：
1. 将证书放到 `data/certs/server.crt` 和 `server.key`
2. 导出证书到客户端：`python cert_manager.py export --desktop`
3. 重启服务器

更多详情请参考 [安全配置指南](安全配置指南.md)
