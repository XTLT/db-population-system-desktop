# 人口通 - 桌面端（Windows 客户端）

人口通系统的桌面端仓库（PyQt6 客户端），支持本地单机（SQLite）与网络（连接服务端）双模式，是日常数据录入、导入导出、报表处理的主要操作端。

> 本仓库由原 `db-population-system` 拆分而来；服务端与 Web 前端在 `db-population-system-server`，移动端在 `db-population-system-mobile`。

## 功能详解

### 登录与权限

- 网络模式连接服务端登录（HTTPS + 证书固定），本地模式免登录直接使用
- **管理员（admin）**：可导入、导出、备份、删除记录、账户设置等全部操作
- **普通用户**：只读查询与查看（导入/导出等写操作菜单自动置灰）

### 一、人员与户籍管理

**人员查询**：顶部搜索框按姓名检索（网络模式走服务端、本地模式查本地库），结果列表双击进入详情；查看同户家庭成员。

**添加新成员**（新增户 / 家庭视图添加）字段一览：

| 字段 | 说明 |
|---|---|
| 姓名 | 必填 |
| 身份证号 | 必填，输入后自动计算年龄 |
| 与户主关系 | **标准下拉（45 项）**：依据公安部户口簿规范 + GB 4761-1984 家庭关系代码 + 民法典近亲属，含户主/配偶/长子/次子/女儿/父亲/母亲/祖父母/兄弟姐妹/儿媳/女婿/岳父母/公婆等；**支持自定义输入**非标准关系 |
| 地址 | 同户已有成员时**自动带出**（只读） |
| 小组 | 同户已有成员时自动带出 |
| 年龄 | 由身份证号自动计算（只读） |
| 电话号码 | 可填 |
| 是否死亡 | 是/否 |
| 社保卡号 1/2/3 | 支持一户口三个社保卡；2/3 号卡由补贴导入自动回填 |
| 脱贫户或监测户 | 脱贫户 / 脱贫不稳定户 / 突发严重困难户 / 边缘易致贫户 |
| 备注 | 自由文本 |
| 残疾 | 是/否；选"是"时展开 **残疾类型**（视力/听力/言语/肢体/智力/精神/多重）+ **残疾等级**（一/二/三/四级） |
| 低保 | 是 / 否 / 低保边缘家庭 / 特困家庭 |
| 是否计生家庭 | 是/否 |
| 是否特困供养 | 是/否；选"是"时展开 **供养类型**（集中供养 / 散居特困） |

**每户唯一户主校验**：添加成员关系为"户主"时，若该户已存在户主，服务端直接拒绝并提示（三端统一生效）。

**换户主整户关系重建**：把某成员改为"户主"时，系统自动重算全户成员与新户主的关系：
- 子女接任户主 → 旧户主变父/母、配偶变父/母、其他子女按年龄自动变兄/弟/姐/妹、旧户主父母变祖父/祖母、岳父母变外祖父/外祖母
- 配偶接任户主 → 旧户主变夫/妻、旧户主父母变公婆/岳父母
- 无法确定归属的关系（孙辈、儿媳等）保持原值不强行改错

**户籍操作**（户籍管理菜单）：
- **新增户**：创建新户并添加户主
- **分户**：把部分成员拆分为独立新户
- **合户**：把两户合并为一户
- **找回已删除人员**：恢复误删的成员

### 二、Excel 批量导入 / 导出（文件菜单）

- **导入 Excel**：按官方模板批量导入人口、补贴等数据（仅管理员）
- **导出 Excel**：按当前查询/筛选结果导出
- **手动备份**：立即备份数据库（另支持自动备份）

### 三、报表填写

- **导入 Excel**：把上级/外部报表数据导入系统
- **在线编辑**：报表数据在线直接修改
- **导出 Excel**：生成报表文件
- **查看修改日志**：追溯报表的每次修改记录
- **一键导入证件号码**：**支持导入数据库内的全部字段**（不只是证件号码本身），按身份证号批量匹配并回填到人员记录

### 四、林地管理

- 查看林地信息、导入林地面积、导出林地数据（林地面积与人员关联）

### 五、学生管理

- **学生信息查询**：按姓名/就读信息检索
- **导入就读信息**：批量导入学校、年级、入学日期等（仅管理员）
- **导出就读信息**：导出学生就读数据
- **年级升级**：到学年自动晋升年级

### 六、补贴数据管理

**地力补贴**：导入地力补贴、查看地力补贴（每年一个值）

**补贴发放**（导入 + 查看，查看窗口支持按条件筛选、删除选中、导出 Excel）：

**低保发放**字段（与民政低保发放模板一致）：
> 费款所属期、姓名、身份证号、村名称、性别、和申请人关系、共同生活家庭成员、享受保障人口数、家庭保障总金额、家庭最低生活基本保障金、家庭特殊困难补助金、家庭调剂金额、特殊困难情形（分类施保）、特殊困难补助金、初始享受时间、始发年月、导入来源

**特困发放**：特困供养人员救助金发放数据（导入/查看）

**残疾人护理补贴**：导入/查看

**养老保险**：导入养老保险、查看养老保险

**高龄补贴**：导入高龄补贴、查看高龄补贴

### 七、下载模板（9 个标准模板）

人口信息导入模板、就读信息模板、林地面积模板、地力补贴模板、养老保险模板、低保发放模板、特困发放模板、残疾人护理补贴模板、高龄补贴模板

（模板字段与导入功能一一对应，按模板填好直接导入）

### 八、更新与账户

- **检查更新**：连接服务器检查新版本（服务器主源 + SHA256 强校验，杜绝下载旧包/坏包）→ 下载 → 立即更新并重启 / 暂不更新
- **账户设置**：修改登录密码等
- **系统托盘**：最小化到托盘后台运行
- **操作日志**：关键操作记录可查

## 运行

```bash
# 本地模式
./start_desktop.sh local

# 网络模式（连服务端）
./start_desktop.sh network https://服务器IP:5000
```

Windows 下开发运行：

```powershell
python -m venv venv
.\venv\Scripts\pip install -r requirements_desktop.txt
.\venv\Scripts\python main.py
```

## 打包（Windows 安装程序 exe）

```bash
pip install -r requirements_desktop.txt pyinstaller
pyinstaller --noconfirm 人口通.spec     # 生成 dist\人口通\
```

再用 Inno Setup 6 编译 `人口通_installer.iss` 生成一键安装 exe（安装包含网络模式证书固定所需的客户端证书）。

## 目录结构

```
main.py               # 入口（MainWindow 骨架，方法绑定自 ui/main_window/）
ui/main_window/       # MainWindow 方法，一方法一文件（搜索/导入/导出/模板/更新/户籍等）
dialogs/              # 各业务对话框（人员添加/编辑、低保/特困/养老/高龄/地力补贴查看、报表等）
core/                 # 数据库（模型一文件一表）、配置、工具
data/                 # Excel 导入器 / 模板生成
network/              # 网络模式客户端（API 封装）
updates/version.json  # 内置版本号（打包读取）
certs/                # 客户端 SSL 证书（证书固定）
```

## 数据库

- 本地库：`core/population.db`（启动自动迁移）
- 备份：`core/data/backups/`（自动 + 手动）
